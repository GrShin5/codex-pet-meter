# v0.1.1 verification / 検証

The source verifier uses deterministic fixtures and synthetic images without authentication, network access, real logs, or preference writes. Run from the source checkout:

```bash
tools/verify-hunger-meter.sh
```

Release verification passed: 115/115 self-tests, 48 standard synthetic previews plus the public Pro preview, and 13/13 installer and packaging tests. The packaged app targets arm64 and macOS 13 or later; strict signature verification passed. Runtime was tested on macOS 27.0.1; older supported macOS versions have not been runtime-tested.
